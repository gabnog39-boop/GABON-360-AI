## Ce qui était potentiellement oublié

Les anciennes versions montrent surtout quatre familles qui ne doivent pas disparaître sous prétexte qu'elles ne sont pas des « modules terrain » :

1. **Mémoire territoriale** : historique, évolution, chronologie et contexte.
2. **Orchestrateur national / système nerveux** : coordination de toutes les IA.
3. **Gouvernance propriétaire + administration + accès payant** : gestion des utilisateurs, rôles, autorisations et modèle d'accès.
4. **Surveillance continue + fusion de données + moteur événementiel** : analyse en arrière-plan et corrélation avant notification.

Ces fonctions sont maintenant intégrées à l'architecture cible comme services/pages de premier niveau.

### C. Services transversaux
- Rapports
- Statistiques
- Qualité des données

- Cybersécurité défensive

### D. Gouvernance
- Espace propriétaire
- Administration

- Abonnements / accès payant
- Audit / traçabilité

Aucune de ces anciennes fonctions ne doit être supprimée simplement parce qu'une version plus récente porte un autre numéro : la règle est de **fusionner la fonction dans la page/service final**, sans multiplier les applications.
